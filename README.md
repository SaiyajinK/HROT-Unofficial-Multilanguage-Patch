<h3>✅ Installation :</h3>

<table align="center">
<tr><th>Step</th><th>Action</th></tr>
<tr><td>1️⃣</td><td>Download the latest release <a href="https://github.com/SaiyajinK/HROT-Unofficial-Multilanguage-Patch/releases/latest">here</a></td></tr>
<tr><td>2️⃣</td><td>Extract the archive into your HROT installation folder</td></tr>
<tr><td>3️⃣</td><td>Run <code>HROT.bat</code> and select your language</td></tr>
<tr><td>4️⃣</td><td>Launch the generated <code>HROT_localized.exe</code></td></tr>
</table>

</p>
  <img width="700" height="1" src="https://via.placeholder.com/700x1/262626/262626">
</p>

<h3>🎮 Steam Launch Options :</h3>

<p>To launch the translated version directly through Steam, use Steam launch options of HROT game :</p>

<pre>"Your_drive\Steam\steamapps\common\HROT\HROT_localized.exe" %command%</pre>

<p><sub>Replace the example path with your actual HROT installation directory.<br>Example : "D:\Games\Steam\steamapps\common\HROT\HROT_localized.exe" %command%</sub></p>
